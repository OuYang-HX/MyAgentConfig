# Agent / Skill / Workflow Development

Agent、Skill、Workflow 三类资产的开发规范与自查技能。

核心纪律：**通用件写通用，场景差异走输入**。判定件（子代理、判定模板、worker 脚本）只认输入不认调用方，编排知识（谁在调、什么时机、拿结果做什么）归编排层。经验收敛自多项目 LLM 编排体系的实战教训。平台无关：不绑定任何编排框架/配置格式，约束的是 agent 开发的通用原则。

## 包含技能

- [`agent-skill-workflow-dev`](skills/agent-skill-workflow-dev/SKILL.md)：双模式技能——
  - **模式一（开发）**：新做或改造子代理 / 技能 / 编排流程时的 7 步流程（定性判断件还是编排件 → 设计输入 → 写定义/模板/脚本 → 接线 → 验证）；
  - **模式二（自查）**：审既有资产的 14 条 finding 清单（架构 / 契约 / 死代码三级），只产出报告不直接改。

## 核心纪律速查

| 级别 | 纪律 |
| --- | --- |
| P0 | 判断件只认输入不认调用方；场景差异 = 输入差异；禁 if-场景分支 |
| P1 | 信号通道唯一；健壮性代码自理；指令只写做什么；业务名不代称；结论止于事实 |
| P2 | 定义与接线同步；任务数据走输入载体不走定义；产物物理隔离 |
| P3 | 独立模块判据；不可达防御必删；无调用方分支必删；私有符号禁跨模块导入 |

触发场景：开发子代理、写技能文档、做编排流程，或对既有 agent/skill/workflow 说"自查一下架构"。
